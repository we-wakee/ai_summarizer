

**AI Summarizer** is a web application that generates concise summaries of text using an **AI-powered API**. Built with **React**, this tool helps users quickly extract key insights from lengthy content.  

### Key Features  
- **AI-Powered Summaries:** Converts long text into clear, concise insights.  
- **React-Based UI:** Fast, interactive, and modern design.  
- **API Integration:** Ensures accurate and efficient text processing.  
- **Fast & Scalable:** Hosted on **Vercel** for seamless performance.  

### How to Use  
1. **Input Text:** Paste the long-form content you wish to summarize into the input box.  
2. **Click 'Summarize':** Press the 'Summarize' button to send the text to the AI API.  
3. **Get Summary:** The AI will process the text and provide a concise summary in seconds.  
4. **Copy & Use:** You can copy the summary and use it for your purposes.
